Payment

A bank payment: initiate one, list yours, load one by id, or cancel one in the hosted flow.

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /api/v1/ob/payments/cancel create The payment has been cancelled successfully
POST /api/v1/ob/payments create The payment object has been stored successfully
GET /api/v1/archive/payments list Returns a page of payments
GET /api/v1/archive/payments/{id} load

metadata.redirectUri string Yes The URI to which the PSU will be redirected once the payment flow is completed.
